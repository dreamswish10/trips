# 旅行手帖 · Trips

家族旅行的行程表集合,每一趟一個子資料夾,純 HTML 無 build。

🌐 https://dreamswish10.github.io/trips/

| 行程 | 日期 | 狀態 | 路徑 |
|---|---|---|---|
| 東京 · 富士山 · 輕井澤 | 2026/12/25 — 2027/1/1 | 規劃中 | [tokyo-2026/](tokyo-2026/) |
| 福岡 · 別府 · 熊本 | 2026/9/19 — 9/25 | 已完成 | [fukuoka-2026/](fukuoka-2026/) |

已結束的行程會打 tag 封存,例如 `trip-2026-fukuoka`。

## 技術

- Pure HTML / CSS / JS,無 build
- Leaflet 1.9.4 (CDN) 做每日地圖
- Google Fonts: Shippori Mincho, Noto Sans TC, Yuji Syuku
