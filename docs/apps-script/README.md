# 行前準備勾選寫入（Apps Script）

讓 `tokyo-2026` 網頁的「行前準備」可以直接勾選，寫回 Google 試算表「東京 2026 行程」的「完成」欄。

- 只能改「行前準備」工作表的「完成」欄，其他工作表、欄位一律拒絕。
- 要通關密碼才能寫入。密碼只存在 Apps Script 裡，不放進網頁程式碼，也**不要放進 GitHub**。
- 網頁送出時會帶項目名稱，Apps Script 會比對試算表那一列的「項目」一致才打勾，避免勾錯列。

## 安裝（第一次，約 5 分鐘）

1. 打開試算表「東京 2026 行程」→ 選單「擴充功能 → Apps Script」。
2. 把編輯器裡原本的程式碼全部刪掉，貼上 `packing-write.gs` 的內容。
3. 把第一行的 `PASSCODE` 改成你們自己的通關密碼，按儲存。
4. 右上角「部署 → 新增部署作業」：
   - 類型選「網頁應用程式」。
   - 執行身分：**我**。
   - 存取權：**所有人**。網頁要能呼叫它；真正擋人的是通關密碼。
5. 按「部署」，第一次會要你授權存取試算表。如果出現「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）」，這是你自己寫的程式。授權畫面應該只要求存取**這一份試算表**（程式第一行的 `@OnlyCurrentDoc` 就是限制這個）；如果要求「所有試算表」，代表少貼了第一行。
6. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`），貼到 `tokyo-2026/index.html` 的 `PACKING_WRITE_URL`。也可以請 AI 助手代貼。

部署網址用瀏覽器打開，看到 `{"ok":true,"message":"行前準備寫入服務運作中"}` 就代表成功。

## 之後要改程式或密碼

在 Apps Script 改完後，要「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址才會保持不變。改密碼之後，網頁會在下一次勾選時重新詢問密碼。

## 網頁端的行為

- 第一次勾選時會跳出輸入密碼的視窗，輸入正確後這支手機會記住。
- 勾下去畫面立刻打勾。試算表發布的資料最多要 5 分鐘才會更新，這段時間網頁用手機記住的狀態，所以重新整理也不會跳回去。
- 寫入失敗（密碼錯、沒網路、項目被改名）時，勾選會恢復原狀並顯示原因。
- `PACKING_WRITE_URL` 是空的時候，勾選框維持唯讀。
